# Cambridge Pseudocode (9618) — Language Support

Syntax highlighting, diagnostics, completion, hover, go-to-definition, outline,
folding, formatting and semantic colouring for **Cambridge International
AS & A Level Computer Science 9618 pseudocode** (see the *Pseudocode Guide for
Teachers*, exams 2026).

Works with `.pseudo` and `.psc` files. Open any pseudocode file and start
typing — diagnostics appear in the Problems panel, hover shows symbol details
and built-in documentation, `F5`/`F12` jumps to declarations, snippets complete
`IF..ENDIF`, `FOR..NEXT`, `CASE OF..ENDCASE` and more.
